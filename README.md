# Голос инструкций — Telegram-бот озвучки инструкций на русском (ElevenLabs)

Telegram-бот превращает текстовые инструкции, памятки и обучающие материалы в аудиофайлы mp3, чтобы их можно было слушать на ходу: за рулём, на складе, на кухне, во время работы руками. Озвучка — нейросеть [ElevenLabs](https://elevenlabs.io), модель `eleven_multilingual_v2` с поддержкой русского языка.

Демо: [@z_elevenlabs_voice_bot](https://t.me/z_elevenlabs_voice_bot)

> Учебный проект: используются только тестовые и вымышленные тексты.

## Что умеет бот

- **Три сценария озвучки**: «Инструкция», «Обучение», «Памятка» — у каждого свой голос, темп и длина пауз.
- **Чтение шагов**: нумерованные пункты `1.`, `2)` читаются как «Шаг 1», «Шаг 2», после каждого шага — пауза, чтобы слушатель успел его выполнить.
- **Подготовка текста**: убирает markdown-разметку, эмодзи и ссылки, раскрывает сокращения (т.е., и т.д., см., №, °C). Смысл и формулировки не меняются.
- **Длинные тексты до 5000 символов** (≈ 6–7 минут аудио): бот режет текст по пунктам и предложениям, озвучивает частями с учётом соседних частей и склеивает в один mp3. В чате видно «Часть 2 из 4».
- **Текст или файл .txt**: инструкцию можно прислать сообщением или файлом (UTF-8 и Windows-1251).
- **Пять женских голосов** с описанием и кнопкой «▶️ пример» — можно выбрать голос на слух.
- **Настройки запоминаются**: выбранные сценарий и голос сохраняются и переживают перезапуск бота.
- **Сохранение файлов**: каждый mp3 приходит в чат и сохраняется на компьютер в папку `audio/`.
- **Остаток квоты**: команда /quota показывает, сколько символов ElevenLabs осталось в этом месяце.
- **Понятные ошибки**: длинный текст, неподходящий файл, закончился лимит, неверный ключ, нет связи — бот объясняет, что случилось и что сделать.

## Как пользоваться

| Команда | Что делает |
|---|---|
| `/start` | приветствие и выбор сценария |
| `/mode` | сменить сценарий: инструкция, обучение, памятка |
| `/voice` | сменить голос, прослушать примеры |
| `/help` | что подойдёт для озвучки, что бот делает с текстом, лимиты |
| `/quota` | остаток символов ElevenLabs в этом месяце |

1. `/start` → выберите сценарий кнопкой. Если пропустить — будет «Инструкция».
2. Пришлите текст сообщением или файлом `.txt`.
3. Бот напишет, сколько символов, какой сценарий и голос, и пришлёт mp3. Файл сохранится в `audio/` с именем вида `2026-11-20_143015_instruction_Alice.mp3`.

## Как бот готовит текст к озвучке

Пример — что вы присылаете и что бот прочитает:

```text
## Как заменить картридж 🖨
Перед началом выключите принтер (см. https://example.com/help).
1. Откройте переднюю крышку
2) Дождитесь, пока каретка остановится -> **не трогайте** её руками!!!
- проверьте, что в комнате не ниже 15°C
```

```text
Как заменить картридж. Перед началом выключите принтер (смотрите ссылка в тексте).
Шаг 1. Откройте переднюю крышку. [пауза 1 с]
Шаг 2. Дождитесь, пока каретка остановится — не трогайте её руками! [пауза 1 с]
Проверьте, что в комнате не ниже 15 градусов. [пауза 1 с]
```

| Что в тексте | Что делает бот |
|---|---|
| `1.` `2)` в начале строки | «Шаг 1.» (в «Обучении» и «Памятке» — «Пункт 1.») + пауза |
| `-` `•` `*` в начале строки | убирает маркер, делает фразу с большой буквы + пауза |
| Заголовок без точки | ставит точку, чтобы не слился со следующей фразой |
| `**жирный**`, `# заголовок`, `` `код` `` | убирает разметку, текст оставляет |
| `[текст](ссылка)` | оставляет только текст |
| `https://…` | «ссылка в тексте» |
| Эмодзи | удаляет |
| т.е., и т.д., и т.п., т.к., см., напр., прим., др. | то есть, и так далее, и тому подобное… |
| `°C`, `№`, `&`, `->`, `→` | градусов, номер, и, тире |
| `!!!`, `???` | один знак |

Паузы делаются тегом ElevenLabs `<break time="1.0s" />` и не влияют на смысл текста. Правила — в [text_prep.py](text_prep.py), их легко дополнить своими сокращениями.

## Сценарии озвучки

| Сценарий | Для чего | Голос | Темп | Пункты | Пауза |
|---|---|---|---|---|---|
| 📋 Инструкция | шаги, которые выполняют руками | Alice | 0,92 | «Шаг 1» | 1,0 с |
| 🎓 Обучение | уроки, регламенты, онбординг | Matilda | 1,0 | «Пункт 1» | 0,6 с |
| 📌 Памятка | короткие напоминания, чек-листы | Laura | 1,08 | «Пункт 1» | 0,4 с |

При выборе сценария ставится его голос. Другой голос можно выбрать через `/voice` — сценарий при этом останется.

| Голос | Характер | Для чего |
|---|---|---|
| Alice | уверенный, чёткий | инструкции (по умолчанию) |
| Matilda | деловой, грамотный | обучающие тексты |
| Laura | живой, энергичный | памятки, анонсы |
| Sarah | мягкий, спокойный | медитации, вводные для клиентов |
| Lily | бархатный, неспешный | длинные спокойные тексты |

## Ограничения

Бот намеренно **не делает**:

- не редактирует, не сокращает и не исправляет текст — читает как есть;
- не проверяет, правильная ли инструкция;
- не монтирует аудио: без музыки, эффектов и нескольких голосов;
- не принимает голосовые, фото, видео, `.docx` и `.pdf` — только текст и `.txt`.

Лимиты: до 5000 символов за раз, файл до 100 КБ. Бесплатный тариф ElevenLabs — 10 000 символов в месяц.

## Структура проекта

```
config.py          настройки: токены из .env, модель, голоса, сценарии, лимиты
text_prep.py       подготовка текста: разметка, сокращения, шаги, паузы, нарезка на части
voice.py           ElevenLabs API: озвучка по частям, склейка mp3, пример голоса, квота
main.py            Telegram-бот: команды, кнопки, приём текста и .txt, отправка аудио
docs/assistant.md  системный промпт и база знаний ассистента
requirements.txt   зависимости с зафиксированными версиями
.env.example       шаблон файла с ключами
audio/             готовые mp3 (создаётся сам, в git не попадает)
data/settings.json выбранные пользователями сценарий и голос (создаётся сам)
```

## Как это работает внутри

```
Текст / .txt ──► text_prep.prepare()   разметка, сокращения, «Шаг N», паузы
                     │
                     ▼
                проверка длины        > 5000 символов → просим разделить, в API не идём
                     │
                     ▼
              text_prep.split()        части ≤ 900 символов, по пунктам и предложениям
                     │
                     ▼
              voice.synthesize()       часть за частью → ElevenLabs text_to_speech.convert
                     │                 previous_text / next_text — ровная интонация на стыках
                     ▼                 ID3-заголовки частей вырезаются — файл не «щёлкает»
              audio/дата_сценарий_голос.mp3 ──► в чат
```

- Сценарий задаёт параметры ElevenLabs `VoiceSettings`: `speed` (темп) и `stability` (ровность интонации).
- Бот работает на long polling — сервер, домен и вебхук не нужны.
- Ключи хранятся только в `.env`. Тексты пользователей в лог не пишутся — только имя файла и число частей.
- Если озвучка сорвалась на середине, недописанный файл удаляется.

## Установка и запуск в PyCharm

Нужен Python 3.10 или новее.

**1. Получите ключи**

- **Токен бота**: напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя → скопируйте токен.
- **Ключ ElevenLabs**: зарегистрируйтесь на elevenlabs.io (бесплатного тарифа хватает; окно с предложением подписки можно закрыть) → **Developers → API Keys → Create API Key**. Включите доступ:
  - *Text to Speech* — озвучка;
  - *Voices → Read* — примеры голосов;
  - *User → Read* — команда `/quota` (необязательно).

**2. Откройте проект**

`File → Open` → папка проекта. PyCharm предложит создать виртуальное окружение — согласитесь (или `Settings → Project → Python Interpreter → Add Interpreter → Virtualenv`).

**3. Установите зависимости**

Откройте `requirements.txt` и нажмите *Install requirements* в жёлтой плашке, либо в терминале PyCharm:

```bash
pip install -r requirements.txt
```

**4. Настройте ключи**

Скопируйте `.env.example` в `.env` и впишите свои значения:

```
BOT_TOKEN=123456789:AA...
ELEVENLABS_API_KEY=sk_...
```

Файл `.env` не попадает в git — ключи остаются только у вас.

**5. Запустите**

Откройте `main.py` → зелёная кнопка ▶ (или `python main.py` в терминале). В консоли появится `Run polling for bot @...` — бот работает. Остановка — кнопка ■.

> Одновременно может работать только одна копия бота с одним токеном. Если в консоли `TelegramConflictError` — где-то уже запущен этот же бот.

**Запуск без PyCharm** (Linux/macOS):

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # и впишите ключи
python main.py
```

## Настройка

**Параметры в `.env`** (все необязательные):

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `ELEVENLABS_MODEL` | `eleven_multilingual_v2` | модель озвучки; `eleven_flash_v2_5` — быстрее и вдвое дешевле по символам |
| `MAX_TEXT_LENGTH` | `5000` | максимум символов за одну озвучку |
| `CHUNK_SIZE` | `900` | размер части при нарезке длинного текста |
| `AUDIO_DIR` | `audio` | папка для сохранения mp3 |

**Изменить сценарий или добавить новый** — в `config.py`, словарь `MODES`:

```python
"safety": {
    "title": "⛑ Техника безопасности",
    "desc": "медленно и твёрдо, длинные паузы",
    "voice": "Xb7hH8MSUJpSbSDYk0k2",
    "step_word": "Правило",
    "pause": 1.5,
    "speed": 0.85,
    "stability": 0.7,
},
```

Кнопка нового сценария появится в `/start` и `/mode` автоматически.

**Добавить или заменить голос** — в `config.py`, словарь `VOICES`:

```python
VOICES = {
    "Xb7hH8MSUJpSbSDYk0k2": ("Alice", "уверенный, чёткий — для инструкций"),
    "ID_нового_голоса": ("Имя", "описание для пользователя"),
}
```

Voice ID берётся на elevenlabs.io → *Voices* → у голоса «⋯» → *Copy voice ID*. На бесплатном тарифе по API доступны стандартные (default) голоса.

**Добавить своё сокращение** — в `text_prep.py`, словарь `ABBREVIATIONS`:

```python
r"\bг\.": "год",
```

**Тексты сообщений бота** — в `main.py`: приветствие в `cmd_start`, справка — `HELP_TEXT`.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| `KeyError: 'BOT_TOKEN'` при запуске | нет файла `.env` или в нём не заполнен ключ |
| «ElevenLabs отклонил ключ API» | ключ неверный или удалён — создайте новый |
| «Закончился лимит символов» | израсходовано 10 000 символов бесплатного тарифа, лимит обновится в начале следующего периода |
| `/quota` пишет, что нет права | включите *User → Read* у ключа в кабинете ElevenLabs |
| Аббревиатура читается неверно | напишите её так, как произносится: «эс-эм-эс» |
| В файле .txt «кракозябры» | сохраните файл в кодировке UTF-8 |
| `TelegramConflictError` | этот же бот уже запущен в другом месте — остановите вторую копию |

## Технологии

Python 3.12, [aiogram 3](https://docs.aiogram.dev) (Telegram Bot API), [ElevenLabs Python SDK](https://github.com/elevenlabs/elevenlabs-python) (асинхронный клиент), python-dotenv. Без базы данных: настройки пользователей — в JSON-файле.
