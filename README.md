# ElevenLabs Voice Bot

Telegram-бот, который озвучивает текст женским голосом через [ElevenLabs](https://elevenlabs.io) и сохраняет аудиофайлы на компьютер. Подходит для быстрой подготовки медитаций, анонсов, инструкций и других голосовых материалов.

Демо: [@z_elevenlabs_voice_bot](https://t.me/z_elevenlabs_voice_bot)

## Возможности

- Ввод текста прямо в Telegram (до 2500 символов за раз)
- Выбор из 5 женских голосов с описанием и прослушиванием примера
- Возврат готового аудиофайла mp3 в чат
- Сохранение каждого файла в папку `audio/` на компьютере
- Понятные сообщения об ошибках: неверный ключ, закончился лимит, нет связи

| Голос | Характер | Для чего |
|---|---|---|
| Sarah | мягкий, спокойный | медитации (голос по умолчанию) |
| Matilda | деловой, грамотный | обучающие тексты |
| Alice | уверенный, чёткий | инструкции |
| Laura | живой, энергичный | анонсы |
| Lily | бархатный, неспешный | сказки |

## Как пользоваться

1. `/start` — приветствие и кнопки выбора голоса
2. «▶️ пример» — послушать голос, «🎙 Имя» — выбрать его
3. Отправить текст — бот пришлёт mp3, файл сохранится в `audio/`
4. `/voice` — сменить голос

## Структура проекта

```
config.py         настройки: токены из .env, модель, голоса, лимиты, папка для файлов
voice.py          работа с ElevenLabs API: озвучка текста и сохранение mp3
main.py           Telegram-бот: команды, кнопки, приём текста, отправка аудио
requirements.txt  зависимости с зафиксированными версиями
.env.example      шаблон файла с ключами
```

## Установка и запуск в PyCharm

Нужен Python 3.10 или новее.

**1. Получите ключи**

- Токен бота: напишите [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
- Ключ ElevenLabs: зарегистрируйтесь на elevenlabs.io (бесплатного тарифа хватает — 10 000 символов в месяц; окно с предложением подписки можно закрыть) → **Developers → API Keys → Create API Key**. Достаточно доступа к *Text to Speech* и *Voices*.

**2. Откройте проект**

`File → Open` → папка проекта. PyCharm предложит создать виртуальное окружение — согласитесь (или `Settings → Project → Python Interpreter → Add Interpreter → Virtualenv`).

**3. Установите зависимости**

Откройте `requirements.txt` и нажмите *Install requirements* в жёлтой плашке, либо в терминале PyCharm:

```bash
pip install -r requirements.txt
```

**4. Настройте ключи**

Скопируйте `.env.example` в `.env` и впишите свои значения:

```
BOT_TOKEN=123456789:AA...
ELEVENLABS_API_KEY=sk_...
```

Файл `.env` не попадает в git — ключи остаются только у вас.

**5. Запустите**

Откройте `main.py` → зелёная кнопка ▶ (или `python main.py`). В консоли появится `Run polling for bot @...` — бот работает. Остановка — кнопка ■.

> Бот работает на long polling — сервер, домен и белый IP не нужны, достаточно запустить его на своём компьютере. Одновременно может работать только одна копия бота с одним токеном.

## Как изменить настройки

**Добавить или заменить голос** — в `config.py`, словарь `VOICES`:

```python
VOICES = {
    "EXAVITQu4vr4xnSDxMaL": ("Sarah", "мягкий, спокойный — для медитаций"),
    "ID_нового_голоса": ("Имя", "описание для пользователя"),
}
```

Voice ID берётся на elevenlabs.io → *Voices* → у нужного голоса «⋯» → *Copy voice ID*. На бесплатном тарифе по API доступны стандартные (default) голоса ElevenLabs. Голос по умолчанию — `DEFAULT_VOICE_ID`.

**Дополнительные параметры** — в `.env` (необязательно):

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `ELEVENLABS_MODEL` | `eleven_multilingual_v2` | модель озвучки; `eleven_flash_v2_5` — быстрее и вдвое дешевле по символам |
| `MAX_TEXT_LENGTH` | `2500` | максимальная длина одного текста |
| `AUDIO_DIR` | `audio` | папка для сохранения mp3 |

**Тексты сообщений бота** — в `main.py`, в функциях `cmd_start`, `cmd_voice`, `on_text`.
